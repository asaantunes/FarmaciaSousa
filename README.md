# Farmácia Sousa — site de exemplo

Site estático, sem dependências, pronto para GitHub Pages.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie estes ficheiros para o ramo `main`.
2. Em **Settings → Pages**, escolha **Deploy from a branch**.
3. Selecione o ramo `main` e a pasta `/(root)`, depois guarde.
4. O GitHub mostrará o endereço público após a publicação.

Antes de publicar, confirme que os dados de contacto, os serviços e os horários continuam corretos.
